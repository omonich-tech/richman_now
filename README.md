# Табло заработка — live-счётчик по нескольким людям

Статический сайт (HTML/CSS/JS, без сборки и бэкенда), который показывает
карточки сотрудников с окладом, конвертирует его в USD/EUR/RUB по курсу ЦБ
Узбекистана и в реальном времени тикает: сколько заработано сегодня + сколько
это в пересчёте на секунду/минуту/час/день/неделю/месяц/год.

## Быстрый старт

1. Отредактируйте `people.json` — добавьте/уберите людей, впишите реальные
   оклады в суммах (`salaryUZS`, за месяц).
2. Положите фото в папку `photos/` и укажите путь в поле `photo` каждого
   человека. Если фото не найдётся (или ещё не добавлено) — автоматически
   подставится аватар с инициалами, ничего не сломается.
3. Проверьте локально (см. ниже) или сразу запушьте в GitHub.

## Запуск локально

Открыть `index.html` двойным кликом не получится — браузер блокирует
`fetch('./people.json')` для файлов, открытых как `file://`. Нужен любой
локальный сервер:

```bash
# вариант 1 — Python (обычно уже стоит)
python3 -m http.server 8000

# вариант 2 — Node
npx serve .
```

Затем открыть `http://localhost:8000`.

## Деплой на GitHub Pages

1. Создать репозиторий и запушить в него все файлы этой папки как есть.
2. В репозитории: **Settings → Pages → Source** → выбрать ветку (обычно
   `main`) и папку `/ (root)`.
3. Через минуту-две сайт будет доступен по адресу вида
   `https://<username>.github.io/<repo-name>/`.

Никакого сервера, ключей API или переменных окружения не требуется — всё
работает прямо в браузере пользователя.

## Как считаются суммы

Из месячного оклада (`salaryUZS`) выводятся остальные ставки:

- **в месяц** — берётся как есть;
- **в год** — оклад × 12;
- **в день / неделю / час / минуту / секунду** — оклад делится на среднюю
  длину месяца (30.44 дня — это 365/12), поэтому суммы честно помечены как
  «в среднем»: не у всех месяцев одинаковое число дней.
- **«заработано сегодня»** — тикающий счётчик: ставка за секунду × количество
  секунд, прошедших с полуночи по времени браузера посетителя. Он растёт
  прямо на экране без перезагрузки страницы, 24/7, включая ночь и выходные —
  как и просили.

## Откуда курсы валют

Скрипт сначала пробует официальный JSON-эндпоинт ЦБ Узбекистана
(`cbu.uz/ru/arkhiv-kursov-valyut/json/`). У части браузеров/хостингов он
может быть недоступен напрямую с фронтенда из-за политики CORS на стороне
ЦБ — тогда автоматически подключается бесплатный резервный источник
(`open.er-api.com`, без ключа, обновляется раз в сутки), и в шапке сайта
честно написано, какой источник сейчас используется. Если ЦБ отдаёт запрос
нормально с вашего хостинга — будет показан именно официальный курс.

Курсы запрашиваются один раз при загрузке и обновляются автоматически раз в
час — сервер не нужен, всё происходит в браузере посетителя.

## Редактирование через сайт (без ручной правки JSON)

На главной странице внизу есть ссылка **⚙ редактировать данные**, ведущая на
`admin.html` — форму, где можно менять имена, возраст, должности, оклады,
загружать фото, добавлять и удалять людей.

Сайт статический (без бэкенда), поэтому админка сохраняет изменения не «в
себя», а напрямую в ваш GitHub-репозиторий через официальный GitHub REST
API — прямо из браузера. Для этого один раз нужен **Personal Access Token**:

1. `admin.html` → раскрыть «Как получить токен» → перейти по ссылке на
   github.com/settings/personal-access-tokens/new.
2. Repository access → **Only select repositories** → выбрать именно этот
   репозиторий (не давайте токену доступ ко всем репозиториям).
3. Permissions → Contents → **Read and write**.
4. Сгенерировать, скопировать и вставить в поле «Personal Access Token» в
   админке.

**Про безопасность:** токен хранится только в `localStorage` браузера, на
котором вы его ввели, и отправляется только на `api.github.com` — никуда
больше. Он не попадает в код сайта и не виден другим посетителям. Но если
кто-то получит физический доступ к этому браузеру, он сможет достать токен
через консоль разработчика — поэтому не пользуйтесь админкой с чужих/общих
компьютеров, а если токен всё же «утёк» — отзовите его на той же странице
GitHub, где создавали.

Каждое сохранение в админке — это обычный git-коммит в ветку `main`, поэтому
всю историю изменений всегда видно в репозитории на GitHub, а GitHub Pages
пересоберёт сайт автоматически за 30–60 секунд после сохранения.

## Структура проекта

```
index.html      — публичная страница с карточками
admin.html      — форма редактирования данных (сохраняет через GitHub API)
style.css       — оформление публичной страницы (тема «табло»)
admin.css       — оформление админки
app.js          — логика публичной страницы: расчёт, тикер, курсы, рендер
admin.js        — логика админки: чтение/запись people.json и фото в GitHub
people.json     — данные людей (можно редактировать и вручную)
photos/         — фото людей (можно пустую оставить — сработает fallback)
```

## Идеи для развития (не реализовано, но легко добавить)

- **Настоящая анимация "флип-борд"** — сейчас цифры просто обновляются,
  можно сделать покадровую анимацию переворота каждого разряда как на старых
  табло аэропортов.
- **Стрелка курса вверх/вниз** — у ЦБ в ответе есть поле `Diff` (изменение
  курса за день), можно вывести рядом с переключателем валют.
- **Переключатель "24/7 vs рабочие часы"** — сейчас деньги "капают" всегда;
  можно добавить тумблер, чтобы день считался только с 9:00 до 18:00 по
  будням.
- **Мини-сравнения** — "уже заработал на N чашек кофе" — не обязательно, но
  оживляет карточку.
- **Отдельная страница/JSON на человека** — если список большой, можно
  подгружать `people/*.json` вместо одного файла.
- **Приватность** — если это внутренний инструмент компании, а не публичный
  сайт, стоит держать репозиторий приватным или поставить пароль через
  GitHub Pages + Cloudflare Access, а не публиковать оклады коллег открыто.
