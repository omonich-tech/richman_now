1. Подключение к репозиторию

Данные сохраняются напрямую в ваш GitHub-репозиторий через официальный API GitHub. Токен хранится только в этом браузере (localStorage) и никуда, кроме api.github.com, не отправляется.

Как получить токен (1 минута, один раз)
  1. Зайти на github.com/settings/personal-access-tokens/new
  2. Token name — любое, например «zarplata-live-admin»
  3. Repository access → Only select repositories → выбрать именно этот репозиторий
  4. Permissions → Repository permissions → Contents → выставить «Read and write»
  5. Generate token → скопировать значение (оно покажется только один раз) и вставить в поле выше

Токен даёт доступ только к содержимому этого одного репозитория — не к всему аккаунту. Не вставляйте его на чужих/общих компьютерах и не публикуйте его нигде.
