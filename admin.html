Заполните карточки ниже (как обычную форму) — внизу страницы сам соберётся готовый текст. Его нужно скопировать и один раз вставить на GitHub — без риска что-то сломать в скобках и запятых.

Готовый результат — скопируйте и вставьте на GitHub

Куда это вставить (3 шага)
  1. На GitHub открыть файл people.json в репозитории и нажать значок карандаша (Edit this file) справа сверху.
  2. Выделить весь текст в редакторе (Ctrl+A / Cmd+A) и удалить, затем вставить скопированный текст из этой страницы (Ctrl+V / Cmd+V).
  3. Спуститься вниз, нажать зелёную кнопку «Commit changes». Через 30–60 секунд сайт обновится.
